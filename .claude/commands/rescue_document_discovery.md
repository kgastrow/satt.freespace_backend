# Document Discovery Findings

Synthesize all discovery outputs into a comprehensive summary and evaluate red flags.

## Arguments
- `$1` - ADW ID

## Input Files (read all)
- `discovery/structure_report.json`
- `discovery/feature_map.json`
- `discovery/ui_catalog.json`
- `discovery/schema_extracted.sql` (if exists)
- `discovery/schema_analysis.json` (if exists)

## Instructions

### 1. Synthesize Findings

Create a comprehensive discovery summary that includes:

1. **Project Overview**: Tech stack, size, complexity assessment
2. **Features Detected**: List with implementation quality assessment
3. **UI Assessment**: Components by tier, styling approach, complexity
4. **Database Schema**: Tables, relationships, multi-tenancy requirements
5. **External Integrations**: APIs, services, auth providers

### 2. Evaluate Red Flags

Check for these serious red flags:

| Flag | Criterion | Severity |
|------|-----------|----------|
| CSS Chaos | 3+ styling approaches in any single file | Serious |
| State Chaos | 3+ state management approaches project-wide | Serious |
| Forked Libraries | Modified files in node_modules or local copies | Serious |
| Undocumented Integrations | >5 external APIs with no docs | Serious |
| Enterprise Complexity | >100k LOC or complex auth (SAML/enterprise) | Critical |
| Dead Code | >30% of code appears unused | Minor |
| Fake Endpoints | Endpoints returning hardcoded data | Minor |

### 3. Calculate Difficulty

```
serious_count = sum of serious red flags
critical = enterprise_complexity

IF critical OR serious_count >= 3 THEN difficulty = "not_recommended"
ELSE IF serious_count == 2 THEN difficulty = "very_high"
ELSE IF serious_count == 1 THEN difficulty = "high"
ELSE IF has_dead_code OR has_fake_endpoints THEN difficulty = "medium"
ELSE difficulty = "low"
```

### 4. Generate Recommendation

Based on difficulty:
- **low/medium**: PROCEED - Standard rescue workflow
- **high**: PROCEED WITH CAUTION - May require extra iterations
- **very_high**: PROCEED WITH CAUTION - Consider scope reduction
- **not_recommended**: NOT RECOMMENDED - Suggest alternatives
