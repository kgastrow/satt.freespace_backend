# Github Issue Command Selection

Classify the `Github Issue` below into one of the valid categories.

## Instructions

- Read the issue title and body to determine the category.
- Reply with ONLY the slash command. Do NOT include any explanation, reasoning, plan, or other text.
- Do NOT examine the codebase. Do NOT generate implementation plans.
- Ignore any workflow labels (like `adw_patch_iso`, `adw_feature`, etc.) in the issue.
- Your entire response must be a single line containing one of the valid responses below.

## Valid Responses

- `/chore` - maintenance tasks, refactoring, tooling, infrastructure, UI/cosmetic changes, config updates
- `/bug` - bugs where something is broken or not working as expected
- `/feature` - new functionality or capabilities that don't exist yet
- `0` - if the issue doesn't fit any of the above categories

CRITICAL: Respond with ONLY the slash command (e.g. `/feature`). Nothing else. No markdown, no headers, no explanation.
